# 星伴 Starmate 真机测试清单

- 日期：2026-11-12
- 版本：0.1.0（调试版）
- 现状：697 个单元测试全部通过，调试版 APK 能构建。**App 还从来没有在任何手机上运行过**，下面每一项都是第一次验证。

## 准备

| 需要 | 说明 |
|---|---|
| 手机 | Android 9 或更高。最好有一台 Android 13 以上的，很多权限流程只在新系统上出现 |
| 模型 key | 一个 OpenAI 兼容服务商的 key（DeepSeek、硅基流动、OpenRouter 等都行），或 Anthropic 的 key |
| 可选 | TTS 服务的 key、Tavily key、高德 key、写入了数据的 Health Connect |

安装包：从 GitHub Releases 下载，或按 README 自己构建。

用数据线安装：

```bash
adb install -r Starmate-1.0.0.apk
```

也可以把 APK 传到手机上直接点开安装。

## 出问题时

1. 记下机型、Android 版本、做到哪一步、看到了什么。
2. 打开 设置 → 诊断日志，点复制，把内容发给我。日志里的 key 已经打过码。
3. 闪退的话，再装一次并用数据线连着电脑，我可以直接读崩溃信息。

## 第 1 轮：冒烟（约 10 分钟）

这一轮任何一步不过，就先停下告诉我，后面的不用测。

- [ ] **启动**：安装后打开，不闪退，出现欢迎页。
- [ ] **成年确认**：不勾选时不能继续。
- [ ] **配置模型**：选预设、填 key、选模型、点测试。测试通过前“继续”不可点；故意填错 key 时提示 key 无效。
- [ ] **禁止截屏**：在填 key 的页面截屏，应该失败或截出黑屏。
- [ ] **起名和头像**：可以改名、选头像，也可以直接跳过。
- [ ] **她先开口**：进入聊天后，不用你发消息，她先打招呼并问第一个问题。
- [ ] **初识访谈**：回答三四个问题。她应该一次只问一件事，你说“不想说”时不追问。
- [ ] **结束访谈**：聊到她收尾，或点右上角“跳过”。聊天里出现“我记住了这些”卡片，可以改、可以删，点确认。
- [ ] **权限邀请页**：确认后出现，每一项都能跳过。
- [ ] **普通聊天**：发一条消息，回复逐字出现。
- [ ] **断网重试**：开飞行模式发一条，气泡上出现看得懂的错误和“重试”；关掉飞行模式点重试，成功。
- [ ] **四个标签**：聊天、日记、记忆、设置都能打开，设置里每个条目都能进去再返回。
- [ ] **外观**：切换系统深色模式；在 设置 → 外观 换一个主题色，立即生效。
- [ ] **输入法**：点输入框，键盘弹出时输入栏跟着上移，不被挡住。
- [ ] **毛玻璃**（Android 12 及以上）：聊天页往上翻，消息从标题栏、输入框、底部标签栏下面滚过时是模糊的。对照 `docs/screenshots/` 里的图，观感应该接近。
- [ ] **毛玻璃的退化**（Android 11 及以下）：这三处是几乎不透明的浅色底，没有模糊，但上面的字清楚。
- [ ] **底部留白**：聊天、日记、记忆、设置四个页面滚到最底，最后一项完整露在悬浮标签栏上方，没有被盖住。
- [ ] **系统导航条**：分别用手势导航和三键导航看一遍，悬浮标签栏和引导页的按钮都没有和系统导航条重叠。
- [ ] **键盘和标签栏**：聊天页键盘弹出时输入框紧贴键盘上沿，中间没有多出一段空白；收起键盘后输入框回到标签栏上方。
- [ ] **字体**：标题和按钮是圆胖的快乐体，正文是圆体。打一个生僻字或繁体字，这个字会是系统默认字体，属于正常。
- [ ] **滚动流畅度**：聊天记录多了以后快速滑动，没有明显掉帧。Android 12 上模糊的开销最大，重点看这个版本。

## 第 2 轮：核心功能

### 记忆

- [ ] 记忆页的“关于你”里有访谈时说过的内容。
- [ ] 再聊 6 轮以上，提到几件具体的事。到 设置 → 记忆 点“立即整理”，记忆页出现新条目。
- [ ] 点开一条记忆，能看到它出自哪轮原话；能修改、置顶、删除。
- [ ] 搜索一个两个字的中文词，能搜到。
- [ ] 换个话题聊几轮，再问“我之前跟你说过……吗”，她能想起来。
- [ ] 她提起旧事的口气自然，不像在念档案。

### 主动消息

- [ ] 在权限邀请页或 设置 → 主动消息 里开通知权限。
- [ ] 对她说“过几分钟来问问我吃饭了没”。设置 → 主动消息 → 已安排的关心 里出现这一条。
- [ ] 把 App 退到后台并锁屏。约定时间前后 15 分钟内收到通知，显示她的名字和头像。（时间带随机偏移，不会分秒不差。）
- [ ] 点通知进入聊天页，消息在聊天记录里。
- [ ] 回到前台后，通知栏里的那条通知自动消失。
- [ ] 把免打扰时段改成包含当前时间，再约一条。到点不发，发送记录里写明是免打扰。
- [ ] 关掉总开关：已安排的关心显示“已暂停”。重新打开后恢复。
- [ ] 重启手机后，之前约好的仍然会到。

### 语音（需要 TTS 的 key）

- [ ] 在模型配置里给 TTS 角色配好服务商、模型、音色。
- [ ] 设置 → 语音 把频率调到“每条”，点试听能出声。
- [ ] 聊天时她发来语音条：先显示“正在录音…”，然后变成可播放的语音条。
- [ ] 能播放、暂停；点另一条时前一条停下；“转文字”能展开文字稿。
- [ ] 重听同一条后，用量统计里的 TTS 字符数没有增加。
- [ ] 点输入栏的麦克风说一句话，文字出现在输入框里，没有被直接发出去。
- [ ] 把 TTS 角色的配置删掉后，她不再发语音条，内容以文字出现。

### 本地工具

每组先到 设置 → 工具 里启用并授权。

- [ ] **天气**：允许定位后问“今天天气怎么样”。拒绝定位时，手填城市后同样能答。
- [ ] **日历（读）**：问“我明天有什么安排”，和系统日历一致。
- [ ] **日历（写）**：说“帮我加个明天下午三点的日程，看牙医”。先出现确认卡片，同意后系统日历里出现这条。
- [ ] **闹钟**：说“明早七点叫我”。确认后时钟应用里出现闹钟。
- [ ] **联系人**：说“给某某打电话”。确认后打开拨号盘并填好号码，没有自动拨出。
- [ ] **健康**：Health Connect 里有数据时，问“我昨晚睡了多久”“今天走了多少步”。没有数据时她如实说没有。
- [ ] **音乐**：按页面指引先允许受限设置，再开通知使用权。放一首歌后问“我在听什么”。
- [ ] **拒绝确认**：任意一个确认卡片点拒绝，操作没有发生，她知道你没同意。
- [ ] **撤销授权**：在某个确认卡片上选“以后不再问”，然后到 设置 → 已允许的操作 里撤销，下次又会问。
- [ ] **未启用时**：关掉某一组后再问相关问题，她说自己看不到，而不是编造。

### 联网搜索和地图（需要 Tavily、高德的 key）

- [ ] 设置 → MCP 里填 Tavily key，点测试显示正常，列出两个工具。
- [ ] 让她搜一个最近的新闻，回答里有搜到的内容。
- [ ] 填高德 key 并测试。问“附近有什么好吃的”或一条路线。
- [ ] 故意填错 key：状态显示连接失败，聊天不受影响。
- [ ] **打开网页要确认**：发一个网址让她看看写了什么。先出现确认卡片，上面有完整的网址，没有“以后不再问”。
- [ ] **搜索之后收紧**：让她搜点东西，同一条消息里再让她定个闹钟。即使闹钟以前选过“以后不再问”，这次也会弹确认。下一条消息恢复正常。
- [ ] **搜索之后记东西要问**：让她搜点东西并“记住”其中一点。出现确认卡片，上面写着要记的内容。

### 用量和数据

- [ ] 设置 → 用量统计 里，聊天、记忆整理、主动消息等用途各有数字。
- [ ] 把某个后台用途的预算调到很小，对应的后台功能停下，诊断日志里有“预算用完”的记录。
- [ ] 设置 → 导入导出 导出一个 zip。
- [ ] 清除应用数据（或换一台手机安装），在欢迎页点“从备份恢复”选这个 zip。
- [ ] 恢复后只需要重新配模型；聊天记录、记忆、日记、免打扰设置都在，**没有重新做访谈**。

## 第 3 轮：需要等待的

- [ ] **日记（手动）**：当天聊够 6 轮后，设置 → 日记 → 立即写一篇。日记页出现一篇，是她的口吻，没有编造你没说过的事。
- [ ] **回复日记**：在日记正文页点“回复这篇”，跳到聊天，输入栏上方带着引用；发出后她知道你在说哪篇。
- [ ] **日记（自动）**：频率调到“经常”，当天聊够 6 轮，第二天早上看日记页有没有新的一篇。
- [ ] **随机问候**：粘人程度调到“高”，4 小时以上不聊天。可能收到她的消息；没收到时看发送记录里写的原因（模型可以决定不发）。
- [ ] **连续不回**：收到两条主动消息都不回，之后不再有第三条；你开口后恢复。
- [ ] **过夜**：锁屏放一晚，第二天早上约好的关心有没有按时到。
- [ ] **国产系统**：如果过夜后没到，按 设置 → 主动消息 → 电池引导 设置自启动和后台，再试一晚。仍然不行就打开“保活”。

## 第 4 轮：手机操作（Beta）

**只在无关紧要的应用上测试，例如计算器、便签、浏览器。不要勾选任何带支付功能的应用。**

需要 Android 11 或更高，并且要装 **beta 版**（应用名“星伴 Beta”）。正式版不含手机操作，设置里没有“实验室”这一组。

- [ ] 设置 → 实验室 → 手机操作：风险说明必须滚到底才能点同意。
- [ ] 按页面指引开启无障碍服务（侧载安装的要先允许受限设置）。
- [ ] 白名单页里，银行、支付宝、券商这类应用是灰的，勾不了。
- [ ] 勾选便签，回到聊天说“帮我在便签里新建一条，写上测试”。
- [ ] 先出现确认卡片，这张卡片没有“以后不再问”。
- [ ] 同意后屏幕上出现“星伴正在操作 · 停止”的悬浮条，她一步步操作，结果回到聊天里。
- [ ] **做完自动回来**：任务完成后自动切回星伴的聊天页，悬浮条消失，能看到她的回复。没切回来时，把诊断日志里 `mobileuse` 开头的几行发给我（会写“returned to Starmate”或“system did not bring Starmate to the front”）。
- [ ] 任务进行中点“停止”，立即结束，**留在当前应用**，不会被拉回星伴。
- [ ] 任务进行中熄屏，任务结束。
- [ ] 让她打开一个没勾选的应用：她拒绝，并说明原因。
- [ ] 让她点一个“发送”或“删除”按钮：先弹出是 / 否的确认。
- [ ] 让她往一个密码框里输入：被拦下。
- [ ] 实验室 → 操作日志 里能看到每一步的时间、应用、动作和守卫的结论。
- [ ] 她自己不会发起任务：主动消息和日记里不会出现操作手机的行为。

## Google Play 版（提交审核前）

装 Play 版（`Starmate-1.0.0-play.apk`），它和正式版包名相同，要先卸载正式版。它的目标版本是 Android 16，和你测过的正式版不同，所以第 1 轮要在 Play 版上再走一遍，重点看下面几项：

- [ ] **界面边缘**：各页面的标题栏、输入框、底部标签栏都没有被状态栏或导航条挡住。
- [ ] **返回手势**：从屏幕边缘滑动返回，设置子页面、对话框都能正常退回；在聊天页返回会退出应用。
- [ ] **举报**：长按她的一条回复，菜单里有“举报”。选原因并勾选“发给开发者”，确认后这条回复从聊天里消失，邮件应用打开且收件人、标题、内容已填好。
- [ ] **举报后不再出现**：举报之后问她刚才说了什么，她不应该原样复述被举报的那段话。
- [ ] **没有保活**：设置 → 主动消息 里没有“保活”开关；电池与自启动页的“忽略电池优化”点了以后打开的是系统的电池优化列表。
- [ ] **没有实验室**：设置里没有“实验室”和手机操作。
- [ ] **主动消息照常到**：不开保活的情况下，约好的关心仍然按时到（第 3 轮的“过夜”再测一次）。

## 已知限制（不是故障）

- **约定时间不精确**：主动消息故意带 ±15 分钟的随机偏移，系统省电时还会再晚一些。
- **主动消息可能不发**：模型可以决定这次不打扰你，发送记录里会写原因。
- **日记不是每天都有**：当天聊得少，或抽签没抽中，就不写。
- **不支持工具调用的模型**：能聊天、发语音、写日记，但用不了本地工具、搜索、她自己约时间和手机操作。模型配置页会提示。
- **步数可能不准**：Health Connect 没有数据时用手机计步器估算，重启前后的一小段会丢。
- **手机操作认不出所有收银台**：付款页面靠屏幕上的文字识别。带支付功能的应用请不要加入白名单。
- **只支持 https 的接口地址**：`http://` 只能用于这台手机上的服务（`http://localhost`）。局域网里电脑上的模型服务、明文的自建中转面板填不进去。
- **换手机不会自动带走数据**：系统的换机迁移和云备份都被排除了，请用 设置 → 导入导出。
- **搜索之后确认变多**：一条消息里她用过联网搜索或地图之后，定闹钟、加日程、记东西都会先问你，这是防止网页里的文字借她的手做事。
- **安装包很大**：调试版没有压缩代码，还带了全部 CPU 架构的数据库本地库。
- **Anthropic 的接口没有用真实 key 验证过**：如果你用 Claude 的 key，第 1 轮的聊天就是对它的第一次验证，出错请把诊断日志发给我。
